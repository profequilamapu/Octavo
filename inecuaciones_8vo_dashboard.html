¿Qué es una inecuación?

Una inecuación es una desigualdad que contiene una o más incógnitas. Es una relación de orden entre dos expresiones algebraicas.

Símbolos de desigualdad

Símbolo Significado Ejemplo
< Menor que x < 5
> Mayor que x > -2
≤ Menor o igual que x ≤ 10
≥ Mayor o igual que x ≥ -3

Diferencia entre ecuación e inecuación

Ecuación Inecuación
x + 2 = 5 x + 2 > 5
Una solución: x = 3 Infinitas soluciones: x > 3
Igualdad (=) Desigualdad (<, >, ≤, ≥)

Ejemplo:

3x - 5 < 10

Esta inecuación tiene infinitas soluciones: todos los números menores que 5.

Propiedades de las desigualdades

Las propiedades nos ayudan a resolver inecuaciones de forma similar a las ecuaciones.

1. Propiedad de la suma y resta

Si sumamos o restamos un mismo número a ambos lados de una desigualdad, la desigualdad se mantiene.

Si a < b, entonces a + c < b + c
Ejemplo:
x - 3 < 7
x - 3 + 3 < 7 + 3
x < 10

2. Propiedad de la multiplicación y división por positivo

Si multiplicamos o dividimos por un número positivo, la desigualdad se mantiene igual.

Si a < b y c > 0, entonces a·c < b·c
Ejemplo:
2x < 8
2x ÷ 2 < 8 ÷ 2
x < 4

3. Propiedad de la multiplicación y división por negativo ⚠️

Si multiplicamos o dividimos por un número negativo, la desigualdad se INVIERTE.

Si a < b y c < 0, entonces a·c > b·c
Ejemplo:
-2x < 8
-2x ÷ (-2) > 8 ÷ (-2) ← ¡El símbolo cambió!
x > -4
💡 Recuerda: Cuando multiplicas o divides una inecuación por un número negativo, ¡NO OLVIDES cambiar el símbolo de desigualdad!

Resumen de propiedades

  • ✓ Suma/resta: La desigualdad se MANTIENE
  • ✓ Multiplica/divide por positivo: La desigualdad se MANTIENE
  • ✗ Multiplica/divide por negativo: La desigualdad se INVIERTE

Representación en intervalos

Las soluciones de una inecuación se pueden representar como un intervalo en la recta numérica.

Tipos de intervalos

Intervalo abierto: (a, b)

Incluye todos los números entre a y b, sin incluir los extremos.

x ∈ (3, 8) o 3 < x < 8
3 8

Intervalo cerrado: [a, b]

Incluye todos los números entre a y b, incluyendo los extremos.

x ∈ [3, 8] o 3 ≤ x ≤ 8
3 8

Intervalo semiabierto: [a, b) o (a, b]

Incluye un extremo pero no el otro.

x ∈ [3, 8) o 3 ≤ x < 8
3 8

Intervalo infinito: [a, +∞) o (-∞, b]

Se extiende hacia el infinito.

x ∈ [3, +∞) o x ≥ 3
📌 Resumen:
  • Bolita abierta (blanca) = NO se incluye el número
  • Bolita cerrada (rellena) = SÍ se incluye el número
  • ] [ = Intervalo abierto
  • [ ] = Intervalo cerrado

Ejercicios Resueltos

1

x - 4 > 2

Paso 1: Sumar 4 a ambos lados
x - 4 + 4 > 2 + 4
Paso 2: Simplificar
x > 6
Solución: x ∈ (6, +∞)
2

3x ≤ 15

Paso 1: Dividir por 3 (número positivo)
3x ÷ 3 ≤ 15 ÷ 3
Paso 2: Simplificar
x ≤ 5
Solución: x ∈ (-∞, 5]
3

-2x < 8

Paso 1: Dividir por -2 (número negativo) ⚠️
-2x ÷ (-2) > 8 ÷ (-2)
Paso 2: ¡El símbolo se INVIERTE!
x > -4
Solución: x ∈ (-4, +∞)
4

2x + 3 > 11

Paso 1: Restar 3 a ambos lados
2x + 3 - 3 > 11 - 3
Paso 2: Simplificar
2x > 8
Paso 3: Dividir por 2
x > 4
Solución: x ∈ (4, +∞)
5

-3x - 5 ≥ 4

Paso 1: Sumar 5 a ambos lados
-3x - 5 + 5 ≥ 4 + 5
Paso 2: Simplificar
-3x ≥ 9
Paso 3: Dividir por -3 (número negativo) ⚠️
x ≤ -3
Solución: x ∈ (-∞, -3]
